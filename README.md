One funny line of at most 200 characters, picked by a local pairwise tournament over twenty original one-liners scored on the judge's own brief: funny on its own, fast punchline, fresh angle, tight wording, holds up on a second read.

The winning line:

> My AI assistant resigned; it said my prompts were the hardest part of its job.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). Standard library only, deterministic.
